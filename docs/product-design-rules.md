# 製品の見た目・置き場所の決まり（デ○○ の番号と答えだけ）

見た目（角・色・余白・位置・押せない部品の形など）を変えるときは、始める前にこのファイルと `tests/visual/design-spec.json`（検査が期待値を読む「決まりの一覧」）を読む。食い違う変更は、報告の「決めてほしいこと」に書く（恒久ルール35）。

- 本文の正は Drive「ツール制作＞デザイン検討」の `DESIGN-RULES.md`。ここは番号と答えの写しで、経緯は書かない。食い違ったら DESIGN-RULES.md が正。
- 機械で確かめられるものは `design-spec.json` に入れてあり、`tests/visual/blocks-188.mjs`（T216）と、一覧を読む各塊が守る。

## 角の丸み（デ106・デ105・デ62・デ57・デ99・920・919）

- **方針（デ106）：角の丸みは 3px に統一する（見本も製品も）。** 製品へは**未適用**。製品へ移す T（違いの一覧 47 以降を製品へ移す T）が、一覧の `corner.applied` を true にして有効にする。それまで、検査は製品に 3px を要求しない。
- **例外（3px の対象外）**
  - `.stitch-wire-sheet`（結合画像の設定の模式図の紙）は 6px のまま（デ105）。
  - 結合画像（canvas で描くもの）の中と、小窓の中の模式図（`.stitch-wire-*`）は対象外。結合画像の写しなので変えない。
  - 円・錠剤形（角が半円）の部品は対象外（デ106）。`border-radius` が 50%・999px 以上・`var(--uma-r-full)` のもの。一覧は `design-spec.json` の `corner.roundComponents`（今 37 宣言）。
- すでに 3px で決まっているもの：`.rc-tbl-wrap`（★の表の枠。外枠の線を残す。920）・帯のボタン（ツール切り替え・ライト／ダーク。デ57・デ62）・UmaStar の左下の「元に戻す」（デ99）・道具の部品（T212-F）。
- 別の決定で対象外：PC の見出し（UmaStar・UmaExam。641px 以上）は角なし・影なし・下のエリアと同じ幅（919）。

## 置き場所・形

- 効率を指定の「↺」は蹄鉄の行の下の**左下**（製品より高さを増やさない。右下にしないのは金と虹の境目を動かす右端から離すため）。デ60。
- 押せない部品は薄くせず、灰の線・灰の文字・灰の地で示す。デ63。
- 「ウィンドウから取り込む」は 320〜430px で2行にしない。従来折り返していない所を折り返さない。デ86・デ68。
- 小窓の中の押して選ぶ一覧の行は 24px が基準。デ101。
- 取り込みの失敗の箱（`.cap-fail`）と結合画像の引き出しのセットの失敗の箱（`appendStitchErrorBlock`）には注意のアイコンを付ける。デ102・デ103。
- ダークの「選ぶボタン」は製品の形（選んでいる方＝明るい地に暗い字・選んでいない方＝暗い地）。デ104。
- カードを選ぶ窓は上寄り（下端から出さない）。デ74。出る場所を変えるのはおいもさんが決めたときだけ。
- 640px 以下で①②の表の列見出しの「スキル名」を出さない。デ79。セットのタブの枚数を出さない。デ72。
- 結合画像の設定のボタン・小窓の題・設定の見出し・右下の丸ボタンの項目の名前は「結合画像の設定」（aria-label も）。デ83。
