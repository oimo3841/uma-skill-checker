収録データの入力（作業用）

サポートカードの「イベントで得られるスキル」を、ゲーム画面を見ながら手で記録するためのページです。 このページはツール本体の一部ではありません。

使い方

  1. このページは簡易サーバー経由で開いてください。 ファイルを直接開く（file://）と、データを読み込めません。
  2. 下の一覧でカードを探し、「入力する」を押します。「1回目」「2回目」「3回目」の箱が並びます。
  3. スキルが得られた回の箱で「＋ スキル」を押し、名前の一部を入れて選びます。ヒントのレベル（Lv）は 1 が入るので、違えば直します。スキルの無い回は、箱を空のままにします（出力には書かれません）。
  4. その回が選択肢で分かれるときは、箱の見出しで「選択肢で分かれる」を選びます。「選択肢1」「選択肢2」の枠が出るので、ゲームの選択肢の上から順に入れます。スキルが得られない選択肢も、空のまま残します（番号をゲームとそろえるため）。選択肢の中で成功・失敗に分かれるときは「成功・失敗に分ける」を押します。
  5. 選択肢が無く、前の回の成否で結果が分かれる（連続イベントの最後の回など）ときは「結果で分かれる」を選び、いちばん良い結果（成功）を結果1に、ほかを結果2・3…に入れます。
  6. 4回目以降がある（グループのカードなど）ときは、いちばん下の「＋ 4回目を足す」で箱を増やします。
  7. 見て回ってスキルが無いカードは、開いた箱のいちばん下の「イベント無しにする」を押します。
  8. 探しても出てこないスキルは、このページでは足せません。スキルの正本に入ってから（＝data/extended-skills.json に載ってから）選んでください。
  9. 区切りのよいところで、下の出力 A をコピーします。入力が足りないカードは出力に入らず、理由がそのカードの下に赤字で出ます。
  10. data/support-card-event-skills.json に貼って上書きします（ファイル全体を出しているので、そのまま置き換えられます）。
  11. npm run check:catalog を回して、形が正しいことを確かめます。

入力の途中経過はこのブラウザに残るので、閉じても続きから再開できます。 貼り終わってから開き直すと、ファイル側に入った分は途中経過から自動で消えます。 ファイルに入っているカードは「直す」で入力に戻せます。
