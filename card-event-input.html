イベントスキルの入力（作業用）

サポートカードの「イベントで得られるスキル」を、ゲーム画面を見ながら1枚ずつ記録するためのページです。 このページはツール本体の一部ではありません。

使い方

  1. このページは簡易サーバー経由で開いてください。 ファイルを直接開く（file://）と、データを読み込めません。
  2. 下の一覧から1枚ずつ、スキルがあれば「スキルを選ぶ」、見て回って無ければ「イベント無し」を押します。
  3. 区切りのよいところで、いちばん下の出力をコピーします。
  4. catalog-data/support-card-event-skills.json に貼って上書きします（ファイル全体を出しているので、そのまま置き換えられます）。
  5. npm run check:catalog を回して、形が正しいことを確かめます。

入力の途中経過はこのブラウザに残るので、閉じても続きから再開できます。 貼り終わってから開き直すと、ファイル側に入った分は途中経過から自動で消えます。
