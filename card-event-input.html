収録データの入力（作業用）

サポートカードの「イベントで得られるスキル」を、ゲーム画面を見ながら手で記録するためのページです。 このページはツール本体の一部ではありません。

使い方

  1. このページは簡易サーバー経由で開いてください。 ファイルを直接開く（file://）と、データを読み込めません。
  2. 下の一覧でカードを探し、「入力する」を押します。スキルが得られる回ごとに「何回目」を入れます（スキルが得られない回は書きません。「＋ 回を足す」で増やせます）。
  3. その回の選択肢を上から並べます（「＋ 選択肢を足す」）。選択肢が無いイベントは「選択肢なし」のまま。スキルが得られない選択肢も、空のまま残してください（選択肢の番号をゲームとそろえるため）。
  4. 成功・失敗などで結果が分かれるときは、「結果が分かれる」に印を付け、いちばん良い結果（成功）を結果1に、ほかを結果2・3…に入れます。
  5. 「＋ スキル」でスキルを足し、ヒントのレベル（Lv）を入れます。
  6. 見て回ってスキルが無ければ「イベント無し」を押します。
  7. 探しても出てこないスキルは、このページでは足せません。スキルの正本に入ってから（＝data/extended-skills.json に載ってから）選んでください。
  8. 区切りのよいところで、下の出力 A をコピーします。入力が足りないカードは出力に入らず、理由がそのカードの下に赤字で出ます。
  9. data/support-card-event-skills.json に貼って上書きします（ファイル全体を出しているので、そのまま置き換えられます）。
  10. npm run check:catalog を回して、形が正しいことを確かめます。

入力の途中経過はこのブラウザに残るので、閉じても続きから再開できます。 貼り終わってから開き直すと、ファイル側に入った分は途中経過から自動で消えます。 ファイルに入っているカードは「直す」で入力に戻せます。
