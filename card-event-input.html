収録データの入力（作業用）

サポートカードの「イベントで得られるスキル」と、マスターに収録されていないスキルの「タグ」を、 ゲーム画面を見ながら手で記録するためのページです。貼り先が違うので、出力は A と B に分かれています。 このページはツール本体の一部ではありません。

使い方

  1. このページは簡易サーバー経由で開いてください。 ファイルを直接開く（file://）と、データを読み込めません。
  2. 下の一覧から1枚ずつ、スキルがあれば「スキルを選ぶ」、見て回って無ければ「イベント無し」を押します。
  3. 探しても出てこないスキル（イベントでしか得られない金スキルなど）は、その場で「新しく起こす」と収録データに足せます。番号は自動で振られます。
  4. 選んだスキルがまだタグの付いていないものなら、その場でタグを付けられます（付けなくても構いません）。
  5. 区切りのよいところで、下の出力をコピーします。出力は貼り先ごとに分かれています。
  6. catalog-data/support-card-event-skills.json に A を、catalog-data/extended-skills.json に B を貼って上書きします（どちらもファイル全体を出しているので、そのまま置き換えられます）。新しく起こしたスキルは B に入ります。
  7. npm run check:catalog を回して、形が正しいことを確かめます。

入力の途中経過はこのブラウザに残るので、閉じても続きから再開できます。 貼り終わってから開き直すと、ファイル側に入った分は途中経過から自動で消えます。

使い方

  1. 一覧から1件ずつ「タグを付ける」を押し、当てはまる条件にチェックを入れます。
  2. どの条件にも当てはまらないスキル（いつでも発動するもの）は、チェックを入れずに「どれにも当てはまらない」を押します。「未設定」のままとは別の意味になります。
  3. 区切りのよいところで、下の出力 B をコピーし、catalog-data/extended-skills.json に貼って上書きします。

ここに出るのはマスターに収録されていないスキルだけです。マスターの445種はすでにタグが付いているので出ません。 「イベントスキル」の画面で付けたタグも、同じ出力 B に入ります。
